# Interface screenshots

These are real user-supplied NodeRunner interface captures in the Phosphor theme,
not generated mockups or the default first-run state. Device names, aliases,
IP addresses and MAC addresses have been covered with opaque masks for public
use. The Settings image is cropped to room management; the host-details image
is cropped to the panel. Connection/token controls and the surrounding network
view are excluded from those crops. Original PNG metadata is removed.

The source captures precede the version-label update to 0.1.2. The label shown
in the Map capture has been preserved. No device counts or topology were invented.

- `map.png`: room layout, grid sizes, host counters and side lists.
- `registry.png`: room-grouped registry, scan status and editable fields.
- `settings-rooms.png`: room names and minimum-grid selectors.
- `hosts-settings.png`: individual device customization controls.

The original captures remain local and are explicitly excluded from Git.
